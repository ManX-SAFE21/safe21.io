Will-Executor per Umbrel OS

Come si installa

Il Will-Executor si aggiunge dall'App Store di Umbrel, in quattro passi:

  1. Apri l'App Store di Umbrel.
  2. In alto a destra premi ⋯, poi Community App Stores.
  3. Incolla questo indirizzo e premi Add: https://github.com/ManX-SAFE21/safe21-umbrel-apps
  4. Apri lo store SAFE21 e installa Will Executor.

Serve l'app Bitcoin Node già installata su Umbrel.

⚠ Prima di disinstallare, salva il backup

Se disinstalli l'app, Umbrel OS cancella tutti i suoi dati: le transazioni dei testamenti che custodisce e anche i backup automatici settimanali, che stanno nella stessa cartella. Non si possono recuperare.

Prima di disinstallare apri il pannello del Will Executor, vai su BACKUP e premi Download Backup. Salva il file fuori dall'Umbrel, sul computer o su una chiavetta. Dopo una nuova installazione lo ricarichi da Import Transactions from Backup.

Come controllare il file

Ogni file da scaricare è firmato con la chiave di sviluppo di SAFE21, allegata alla release. Nella pagina della release su GitHub trovi anche il codice SHA-256: prima di installare, controlla che quello del file scaricato sia lo stesso.
